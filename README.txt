SACHIN BHARATH — QA ENGINEER PORTFOLIO WEBSITE

FILES
- index.html: Website content
- styles.css: Responsive layout and styling
- script.js: Mobile navigation and current year
- assets/Sachin_Bharath_QA_Resume.pdf: The resume PDF used by every Download Resume button

PREVIEW LOCALLY
1. Extract the ZIP file.
2. Open index.html in a browser.

PUBLISH ONLINE
Upload the contents of this folder to a static website host such as GitHub Pages, Netlify, or your own web hosting. Keep the assets folder beside index.html so the resume download works.

NOTES
- The website uses the information in the supplied resume.
- The contact email and phone links open email and phone apps.
- Google Fonts are loaded online; the website remains readable with fallback fonts if they do not load.
